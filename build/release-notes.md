## Как скачать

- **ModLaunch-Setup-3.0.0.exe** — установщик. Запустите, нажмите «Установить» — через минуту ModLaunch на рабочем столе и в «Пуске». ModHub 2.x обновится на месте: настройки, аккаунт, друзья и моды сохранятся.
- **ModLaunch-3.0.0-win-x64.zip** — портативная версия одной папкой: распакуйте и запустите `ModLaunch.exe`.

Windows может предупредить о неизвестном издателе: «Подробнее» → «Выполнить в любом случае».

## Что нового в 3.0

- **Свой установщик.** Своё окно в стиле ModLaunch: выбор папки, ярлыки, карточки возможностей, пока идёт установка, и конфетти в конце. Удаление — через «Приложения» Windows.
- **Автообновление.** Новые версии приходят сами: ModLaunch заранее скачивает обновление, проверяет его контрольную сумму и по кнопке «Обновление» вверху ставит и перезапускается за несколько секунд.
- **Своя рамка окна.** Никакой белой полосы Windows: свернуть, развернуть и закрыть — аккуратными кнопками в шапке, окно тянется за шапку, двойной щелчок разворачивает.
- **Намного больше анимаций.** Плитки игр наклоняются за мышью, карточки и списки выезжают лесенкой, кнопки блестят при наведении, витрина плавно приближает кадр, друзья «в игре» дышат, окна и уведомления появляются с пружинкой. Всё это отключается в «Настройки → Внешний вид → Анимации».
- **Поиск починен.** Поиск из шапки со страницы игры теперь сразу открывает каталог с найденным (раньше экран оставался на «Установленных»). Enter ищет без задержки.
- **Статистика.** Скачивания каждой версии, отзывы, средняя оценка и самые обсуждаемые моды — на одном экране (для владельца: пять щелчков по номеру версии в «Настройки → О программе»).

## Что было раньше

- **2.2** — новое имя ModLaunch.
- **2.1** — друзья, оверлей в игре по Ctrl+Shift+M, шейдеры через ReShade, автопоиск зависимостей, без «Премиума».

## Для владельца сервера

Чтобы друзья заработали, один раз вставьте правила из `firebase/friends.rules` в консоли Firebase (Firestore Database → Правила), рядом с правилами отзывов, и нажмите «Опубликовать».
