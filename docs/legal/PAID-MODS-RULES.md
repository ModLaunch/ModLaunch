# Правила платных модов ModLaunch

> ⚠️ ЧЕРНОВИК. Проверить юристу. Главный риск — **условия лицензий игр (EULA) и правила модинга издателей**:
> многие издатели запрещают продавать моды к своим играм или разрешают только через свои площадки. **[ЮРИСТ]**

## 1. Когда мод можно продавать

Платный мод разрешён, только если **одновременно**:

1. **Издатель игры разрешает коммерческие моды** — в EULA, правилах модинга или по письменному разрешению.
   Если правила игры прямо запрещают продажу модов (или разрешают только через площадку издателя) — мод можно
   публиковать только бесплатно. Автор обязан указать при выставлении, на каком основании продажа разрешена
   (ссылка на правила или письмо).
2. **Все части мода — ваши** или используются по лицензии, допускающей коммерческое использование (модели,
   текстуры, звуки, код, библиотеки). Нельзя продавать: перезалив чужих модов, моды на основе чужих ассетов без
   разрешения, извлечённые из других игр ресурсы.
3. Мод **не является читом для сетевой игры** и не обходит защиту, DRM или античит.
4. Мод **не требует платить за доступ к чужому бесплатному контенту** (например, к бесплатным зависимостям).

## 2. Что мы проверяем

* Автоматически: вредоносный код (чёрный список, Защитник Windows, VirusTotal), опасные действия в скриптах.
* По жалобам: авторские права, украденные моды, нарушение правил игры.
* Выборочно: основание продажи (п. 1.1).

## 3. Если издатель или правообладатель против

Мод снимается (порядок — DMCA-PROCEDURE.md); покупатели последних 14 дней получают возврат; автор может быть
заблокирован при повторных нарушениях.

## 4. Альтернатива продаже

Бесплатная публикация + кнопка **«Поддержать автора»** (донат). Донат — добровольный и не делает мод платным, поэтому
допустим для большинства игр. **[ЮРИСТ]: подтвердить, что донаты не нарушают EULA игр, запрещающих продажу.**

## 5. Список игр

Ведём список игр с известной позицией издателя (разрешено / запрещено / только через площадку издателя) и
показываем предупреждение при выставлении платного мода к игре из «запрещённых». **[Сделать: заполнить список с
юристом; технически — поле в каталоге игр.]**
