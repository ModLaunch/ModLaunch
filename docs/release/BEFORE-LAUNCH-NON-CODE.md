## Где брать инди-разработчиков

- itch.io и Steam (раздел «Скоро») — небольшие команды из РБ/СНГ/ЕС; писать с конкретным предложением:
  комиссия ниже Steam (≤ 29 % против 30 %), региональные цены, ключи для прессы, бесплатное продвижение на старте.
- Сообщества: Telegram-чаты разработчиков игр, gamedev-конференции (DevGAMM и т. п.), Discord-серверы движков.
- Авторы популярных модов из Thunderstore/Nexus (у многих есть свои небольшие игры).
- Предложение «первой волны»: комиссия 0–10 % на 6 месяцев (настраивается в программе для каждого разработчика).
- Что попросить у каждого: сборку (zip/exe), 5+ скриншотов, описание RU/EN, цены в 4 валютах, право показывать в рекламе.

## Блогеры и пресса

- 20–40 YouTube/Twitch/VK/Telegram-авторов про моды и инди-игры (Minecraft, Valheim, Lethal Company, Stardew, Subnautica —
  игры, которые ModLaunch поддерживает лучше всего).
- Ранний доступ за 1–2 недели + ключи от игр стартового каталога для розыгрышей.
- Пресс-кит: `modlaunchapp.com/press.html` (архив, факты, тексты RU/EN).
- **Видео**: 60–90 секунд реальной программы (запуск → найдены игры → мод в один клик → игра). Снять через OBS;
  монтаж — любой редактор. Положить на YouTube и ссылку — на страницу пресс-кита.

## Подпись кода

- Белорусскому ООО крупные центры сертификации сейчас не выдают сертификаты (санкции). Варианты и стоимость —
