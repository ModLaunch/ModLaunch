## Если что-то упало

**Упала база / «Сервис временно недоступен» у многих**
1. Остановить приглашения. 2. Firebase Console → Usage: нет ли упора в квоты (Spark? → Blaze). 3. Cloud Monitoring:
ошибки `RESOURCE_EXHAUSTED` — нагрузка выросла слишком резко: подождать 10–15 минут, дальше волнами меньше.
4. Сообщение в соцсетях: «пускаем волнами, всё работает, подождите».

**Упали платежи**
1. Аккаунт → Магазин → снять «Магазин открыт» — люди увидят «Оплата картой временно недоступна», деньги не спишутся.
2. Логи `bepaidWebhook`: подпись не сходится → проверить секрет `BEPAID_PUBLIC_KEY`; функция не отвечает → выложить заново.
3. Оплаченные, но не выданные покупки: в базе `payments` со статусом `created`, у платёжной системы — успешные.
   Повторить уведомление из кабинета bePaid (кнопка повторной отправки) — сервер выдаст покупку один раз.
4. Платёжная система лежит целиком → переключить `PAYMENT_PROVIDER` на запасную (WEBPAY), выложить сервер.

**Плохое обновление программы** (падает при запуске)
1. Программа сама вернёт прежнюю версию после трёх неудачных запусков и больше не предложит эту.
2. Сразу: вернуть в `site/update.json` прежнюю версию (или убрать новую), загрузить сайт — новые люди её не получат.
3. Исправить, выпустить версию с номером выше.

**Упал сайт**
1. Ссылка «Скачать» в соцсетях — сразу на GitHub Releases.
2. Сайт за Cloudflare: включить «Always Online»; VPS — перезапустить nginx.

**Вирус в моде или товаре**
1. Модерация → «Снять» с причиной «Вредоносный код» — пропадёт у всех за 30 минут, файл — в чёрном списке.
2. Заблокировать автора. 3. Покупателям — возврат (Аккаунт → Магазин → возврат по номеру).
