# Подпись кода ModLaunch (чтобы Windows не пугала пользователей)

`ModLaunch-Setup-x.y.z.exe` и `ModLaunch.exe` — один и тот же файл, поэтому подписывать нужно один раз.
Сейчас сборки **не подписаны**: SmartScreen показывает «Windows защитила ваш компьютер», часть антивирусов
относится к файлу подозрительно.

## Что важно знать заранее

1. **DigiCert и Sectigo (и их реселлеры) не выдают сертификаты организациям с адресом в Беларуси** — из-за
   санкционных ограничений ([DigiCert](https://knowledge.digicert.com/solution/embargoed-countries-and-regions),
   [Sectigo](https://support.sectigo.com/Com_KnowledgeDetailPage?Id=kA01N000000zFKI)). Купить «обычный» OV/EV
   сертификат на белорусское ООО, скорее всего, не получится. Позицию SSL.com и Certum нужно уточнить у них
   напрямую — по открытым источникам её не видно.
2. **Azure Artifact Signing** (бывш. Trusted Signing, ~10 $/мес) — только для организаций из США, Канады, ЕС и
   Великобритании, и Microsoft требует историю компании от 3 лет
   ([Microsoft](https://learn.microsoft.com/windows/apps/package-and-deploy/code-signing-options)).
3. **SignPath Foundation** (бесплатно) — только для open-source проектов с лицензией OSI; у ModLaunch лицензия
   «все права защищены», так что не подходит без смены лицензии ([SignPath](https://about.signpath.io/product/open-source)).
4. Даже с подписью **SmartScreen не даёт доверие мгновенно**: репутация копится по мере скачиваний. EV-сертификат
   с 2024 года тоже не даёт мгновенного доверия.

## Что я рекомендую (по порядку)

| Вариант | Стоимость | Срок | Плюсы / минусы |
|---|---|---|---|
| **А. Юрлицо в ЕС/UK/США + OV-сертификат с облачным ключом (SSL.com eSigner или аналог)** | регистрация компании ~500–2000 $ + сертификат ~200–400 $/год | 2–6 недель | Нормальная подпись «ModLaunch …». Нужна компания-владелец дистрибуции (часто её и так создают для приёма платежей из-за рубежа). |
| **Б. Тот же юрлицо через 3 года → Azure Artifact Signing** | ~120 $/год | — | Самый дешёвый и удобный способ, но только для «старых» компаний. |
| **В. Пока без подписи** | 0 | сразу | Отправить каждую версию в Microsoft на анализ как разработчик (https://www.microsoft.com/wdsi/filesubmission) — снимает ложные срабатывания Защитника; SmartScreen всё равно будет предупреждать первые недели. |

**Мой выбор для релиза:** вариант В на старте (сделать обязательно для каждой версии) + сразу начинать вариант А.
Юрист должен подтвердить, можно ли белорусскому ООО владеть иностранной компанией для этой цели (валютное
регулирование РБ, санкции).

## Как подключить, когда сертификат будет

Всё уже встроено: `build/sign.ps1` вызывается из `MAKE-SETUP.bat` и из релизной сборки на GitHub
(`.github/workflows/release.yml`, шаг **Sign**). Без настроек сборка проходит без подписи.

* **Сертификат на USB-токене или в хранилище Windows** — `SIGN_MODE=thumbprint`, `SIGN_THUMBPRINT=<отпечаток>`.
  Нужен Windows SDK (signtool). Для CI токен не подходит — используйте облачный ключ.
* **SSL.com eSigner** — `SIGN_MODE=esigner` + `SIGN_ESIGNER_TOOL`, `SIGN_ESIGNER_USER`, `SIGN_ESIGNER_PASSWORD`,
  `SIGN_ESIGNER_CREDENTIAL_ID`, `SIGN_ESIGNER_TOTP`.
* **Azure Artifact Signing** — `SIGN_MODE=azure` + `SIGN_AZURE_ENDPOINT`, `SIGN_AZURE_ACCOUNT`,
  `SIGN_AZURE_PROFILE`, `SIGN_AZURE_DLIB` и вход в Azure (`AZURE_TENANT_ID`/`AZURE_CLIENT_ID`/`AZURE_CLIENT_SECRET`).

Локально — переменные окружения или файл `build/signing.json` (он в `.gitignore`, в репозиторий не попадает).
На GitHub — Settings → Secrets and variables → Actions, те же имена.

После подписи скрипт сам проверяет подпись (`Get-AuthenticodeSignature` = Valid), иначе сборка останавливается.

## Что меняется в программе после подписи

Обновления: если установленная программа подписана, она запустит только обновление, подписанное **тем же
издателем** (`Setup/Signature.cs`, WinVerifyTrust). Подменённый на сайте установщик не пройдёт, даже если кто-то
подменит и контрольную сумму в `update.json`. До подписи проверяется только SHA-256, как раньше.

## Проверить руками

1. Скачать Setup с сайта на чистый ПК → свойства файла → вкладка «Цифровые подписи» есть, издатель верный.
2. Запустить → окно SmartScreen показывает издателя, а не «Неизвестный издатель».
