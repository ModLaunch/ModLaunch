# Новый Creator Hub (C#-версия)

Дата: 2026-09-26
Касается: `desktop/ModLaunch`, раздел Creator Hub. Продолжение минималистичного редизайна
(`2026-09-26-minimal-redesign-design.md`): тот же стиль, те же общие элементы.

## Зачем

Автору не нравятся вид и удобство Creator Hub. В раздел заходят за двумя вещами одинаково часто:
смотреть моды сообщества и делать свои. Задача — новые экраны, понятные новичку, и новый логотип.

## Что решили

- **Подход А:** «начинка» не меняется (ModScript, сборка, установка, публикация, загрузка из Hub —
  файлы `Creator/*.cs` не трогаем). Экраны пишутся заново.
- **Логотип — вариант A:** кубик мода с искрой, белый значок на плитке с градиентом
  от `#9D85FF` к `#EC4899`, скругление ~27% стороны.
- **Стартовая страница «Главная»** — новый экран по умолчанию.
- **По умолчанию (можно изменить при проверке документа):**
  - вкладка «Мои публикации» переезжает внутрь «Моих модов»;
  - «Примочки» переименовываются в «Шаблоны» (англ. «Templates»).

## Структура

Вкладки через `Ui.TabBar` (как в остальной программе):
**Главная · Hub · Мои моды · Шаблоны · Справка**.

Внутренние id: `home`, `hub`, `mine`, `examples`, `docs`. Id `examples` сохраняется, потому что на него
ссылается `Program.cs`. Старый id `published` продолжает работать и открывает «Мои моды» на части
«Опубликованные». По умолчанию `new CreatorPage()` открывает `home`.

Код экранов делится по файлам (все — `partial class CreatorPage`):

| Файл | Что внутри |
| --- | --- |
| `Views/CreatorPage.cs` | состояние, шапка с логотипом и вкладками, переключение экранов, сохранение |
| `Views/CreatorPage.Home.cs` | новая «Главная» |
| `Views/CreatorPage.Mine.cs` | «Мои моды»: проекты + опубликованные |
| `Views/CreatorPage.Editor.cs` | редактор (перенос из `CreatorPage.cs`) |
| `Views/CreatorPage.Templates.cs` | «Шаблоны» (бывшие примочки) |
| `Views/CreatorPage.Docs.cs` | «Справка» с оглавлением |
| `Views/HubViews.cs` | Hub (остаётся, правится) |
| `Views/CreatorLogo.cs` | логотип: плитка любого размера и значок для боковой панели |

## Экраны

**Шапка раздела.** Логотип 44 px, «Creator Hub» (`h2`) и короткая подпись. Под ними строка вкладок.

**Главная.**
1. Приветствие: логотип 72 px, «Creator Hub», одна строка «Делайте свои моды и находите моды сообщества».
2. Две большие карточки-кнопки рядом: **«Создать мод»** (акцентная, открывает новый проект из
   шаблона «Чистый лист») и **«Опубликовать мод»** (обычная, открывает окно публикации архива).
3. «Продолжить работу» — до 4 последних проектов карточками. Если проектов нет, раздел не показывается.
4. «Популярное в Hub» — 6 модов по тренду (те же карточки, что в Hub), ссылка «Все» ведёт на вкладку Hub.
   Пока грузится — заглушки; если ошибка сети — одна строка текста.
5. «Начни с шаблона» — 3 шаблона, ссылка «Все» ведёт на «Шаблоны».

**Hub.** Функции те же. Хэштеги в одну строку с прокруткой вбок (не обрезаются). Строка цифр
(моды, авторы, загрузки, лайки) — простые числа с подписями, без плиток с иконками.

**Мои моды.** Две части: «Проекты» и «Опубликованные» (бывшая вкладка). У проектов — сетка карточек
с картинкой игры, названием, игрой и «изменён …». Первая карточка — «+ Новый мод» (пунктирная).
Если проектов нет — большая пустая карточка с кнопками «Создать мод» и «Шаблоны».
Если пользователь не вошёл в аккаунт, в «Опубликованных» — одна строка с кнопкой «Войти».

**Редактор.** Логика та же. Кнопки вставки (`needs`, `config`, `edit` …) — чипы с рамкой-фоном
(`Button.chip`), чтобы было видно, что на них можно нажать.

**Шаблоны.** Фильтры по категориям — чипы. Карточка шаблона целиком нажимается и открывает его;
кнопка «Попробовать» — обычная, не акцентная.

**Справка.** Слева оглавление (список разделов, фиксированной ширины ~220 px), справа разделы.
Клик по пункту прокручивает к разделу. Тексты справки не меняются.

**Логотип на боковой панели.** Значок кубика с искрой вместо молотка с отвёрткой (`Icons.Tools`)
на кнопке Creator Hub, в палитре команд и в поиске.

## Тексты

Меняются: `cr.tab.mine` → «Мои моды» / «My mods», `cr.tab.examples` → «Шаблоны» / «Templates»,
`cr.subtitle` → «Моды сообщества и мастерская» / «Community mods and workshop».
Добавляются: `cr.tab.home`, тексты «Главной» (заголовки разделов, карточки). Оба языка.

## Проверка

- Сборка без ошибок, `--selfcheck` проходит (там есть проверки Creator Hub).
- Снимки экранов: существующие `10a`–`10d`, `11a`–`11h` плюс новый `10-creator-home`.
  Сравнение «было / стало», светлая тема для «Главной».

## Чего не делаем

- Не меняем язык ModScript, сборку, установку, публикацию и работу с сервером Hub.
- Не меняем страницу мода из Hub (она общая со страницей мода) и окно публикации (кроме полей, уже исправленных).
- Тексты справки и шаблонов не переписываем.
